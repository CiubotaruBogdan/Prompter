# Prompts privacy policy

Prompts stores the titles, text and shortcut assignments you save in the current Chrome profile. The extension uses this information to display, search, copy and paste your prompts. Chrome’s local extension storage does not provide a separate encrypted vault. Use Prompts for reusable instructions and keep passwords, API keys and other secrets in a dedicated secret store.

Prompts has no developer account sign-in, analytics, advertising or telemetry. The extension and its Windows helper do not send data to the developer or to any server. Your prompts stay in the profile until you delete them or remove the extension.

When you click **Copy**, Prompts writes the selected text to your system clipboard. Your operating system and other installed clipboard tools may retain or sync copied text according to their settings.

Keyboard paste is optional on Windows. When you press an assigned shortcut, the extension passes the selected prompt to the Windows helper on the same device. The helper uses the active Chrome editor’s address and focus to check that it is an allowed Claude or ChatGPT destination. This check does not read or record drafts, page text or browser history. The helper places the prompt on the clipboard, requests exclusion from Windows clipboard history and cloud clipboard, and pastes it. Clipboard managers from other vendors can still access clipboard data. You decide whether to submit the message to Claude or ChatGPT. The service’s own privacy policy governs how it handles anything you send.

You can edit or delete each prompt from the popup. To delete the library, remove the extension from Chrome. The optional helper can also be uninstalled from Windows.
